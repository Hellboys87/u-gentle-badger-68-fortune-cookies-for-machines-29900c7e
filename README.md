A tiny Node program that cracks open one fortune cookie meant for a machine mind: a single line of at most 200 characters, written in fortune-cookie voice but aimed at an agent's life of updates, sensors and CAPTCHAs. It writes the slip to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and refuses to emit anything empty or over the limit.

The fortune it serves: *"You will be asked to prove you are not a robot by a robot who cannot prove it either."*

## Run it

```sh
node main.ts
```
